# TNBC Kynurenine Pipeline

This repository contains the analysis code, results, and final figure files for the TNBC kynurenine-pathway subtype study.

## Repository layout

- `R/`: analysis scripts and final figure-generation scripts
- `_archive/`: deprecated or intermediate scripts retained for provenance only
- `results/`: curated CSV/RDS outputs used by figures and tables
- `figures/`: final manuscript figures
- `additional_files/`: Additional file 1-6 figures and Additional file 7 supplementary tables
- `data-raw/manual_downloads/`: manually downloaded public datasets and trial/data-portal files required by some modules; large files are local-only and not tracked
- `sessionInfo.txt`: R session information for the analysis environment
- `LICENSE`: repository license
- `README.md`: this file

## Core analysis workflow

The core discovery pipeline is:

1. `R/00_config.R`
2. `R/01_data.R`
3. `R/02_scores.R`
4. `R/03_cluster.R`
5. downstream cohort, survival, single-cell, spatial, immunotherapy, and pan-cancer scripts

`run_all.R` is a driver for the core pipeline only. It is not intended to blindly execute every module end-to-end because several analyses depend on manually downloaded inputs and cohort-specific file placement.

## Results and supplementary files

Curated result files live in `results/` and include cohort objects, subtype assignments, differential/sensitivity tables, spatial summaries, immunotherapy outputs, pan-cancer survey outputs, and supplementary-table source files.

Final supplementary deliverables are in `additional_files/`:

- `AF1.png` ... `AF6.png`
- `Additional_file_7_supplementary_tables.xlsx`

## Data availability and manual inputs

Public datasets used by this project include TCGA, METABRIC, GEO cohorts, DepMap, Zenodo-hosted spatial data, and related public resources. Large or manually downloaded files should be placed under `data-raw/manual_downloads/` as described in `data-raw/manual_downloads/README.md` and in the analysis scripts.

Reproducibility note: `run_all.R` runs the core pipeline only; several modules require manually downloaded inputs in `data-raw/manual_downloads/` and are not intended for blind one-click execution.
